# R0 — Walking skeleton (L) — status: open

One simulated driver's position travels from device to map through every layer,
on the local Kubernetes cluster, delivered declaratively, with one trace spanning
the whole path.

## In
- One simulated driver (`simulator/`), posting `position.reported` over HTTP with
  device sequence number and device timestamp.
- Ingest gateway: validates, normalizes, static token auth, writes to the log keyed by driver id.
- Event log: Apache Kafka 4.x in KRaft mode, one combined broker-and-controller node,
  one topic `position.reported` (`docker compose`: the official `apache/kafka` image;
  kind: the Strimzi operator with a `KafkaNodePool`).
- Location projector: consumes, keeps newest-by-sequence per driver in Redis
  (`HSET` + `GEOADD`), fleet-prefixed keys.
- Live gateway: WebSocket, pushes every update (no cells yet) to a static MapLibre page.
- Declarative deployment: kind cluster, Kustomize `local` overlay, Argo CD syncing `deploy/`.
- Delivery pipeline: GitHub Actions — build, `go test`, images to GHCR.
- One OpenTelemetry trace from simulator through the log to the WebSocket push.

## Out
Zones, orders, history, scaling, auth beyond a static token, cells, coalescing,
dedupe beyond newest-wins, metrics dashboards.

## Sittings (planned)

   module, four binaries, dot moves, trace visible. Stop there.

## Deferred (found during the slice, not done here)
- Map page (`services/live-gateway/web/`) expects the live gateway to serve it at `/` and
  push `{driver_id, seq, lat, lon}` (one object or an array) on `/ws`; the gateway itself
  is still to build.
- The page carries a copy of `docs/design/console/tokens.css` (`go:embed` cannot reach
  `docs/`); one source once R2 creates `web/`.
- Dots step at report rate, no gliding; every driver draws as Available (R0 has no activity).
- Basemap reads public OpenFreeMap tiles and glyphs (Noto Sans labels, not the UI font);
  the demo needs network access until tiles are self-hosted.
- Projector compares device seq only; device session (decision 4) is R1. Until then the
  simulator starts its seq at boot time (Unix ms) so a restart is not held behind the last run.
- Fleet id comes from the report body, not the token; the live gateway has no auth on
  upgrade, no fleet filter and no per-stream sequence (decision 15 / R3b, R2).
- `position.reported` has 6 partitions locally, a placeholder until decision 11 sizes it;
  created by the `kafka-topics` one-shot in compose, auto-create is off.
- Event codec is JSON and trace context rides in Kafka record headers and in the pub/sub
  payload's `trace` field, not in the event envelope (decision 10, R3).
- No checker exists yet; invariant 4 is covered by the projector's newest-wins tests only.
- Tempo keeps traces on tmpfs (lost on container restart) and has no container healthcheck
  (distroless image); readiness is `GET :3200/ready`.
- Live fan-out loss rule: Redis pub/sub is lossy; newest-wins per driver, the next update
  heals a missed one; a new socket gets no snapshot until it receives an update.
- Ingest has no in-flight limit or load shedding with 503 + Retry-After (R1, decision 8).
- `INGEST_TOKEN` defaults to `dev-token`; the gke overlay must set it from a Secret with
  no default (sitting 2).
- Projector runs one EVALSHA per record, not pipelined (R1 load).
- Simulator seq from wall-clock ms freezes the driver if the clock steps back; event id
  `fleet:driver:seq` has no session either (R1 sessions, decision 4).
- No Content-Security-Policy header on the map page.
- Event id `fleet:driver:seq` collides once R1 sessions restart seq; R1 adds the session id to it.
- Skipped invalid records are only logged; export a metric the checker can count, and
  record the validator version so replay skips the same records.
- A record that passes `Validate` but fails deterministically in Redis (e.g. WRONGTYPE) stops
  all partitions and crash-loops the projector; accepted under at-least-once for R0,
  dead-letter later.
