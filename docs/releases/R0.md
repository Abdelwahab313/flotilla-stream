# R0 — Walking skeleton (L) — status: open

One simulated driver's position travels from device to map through every layer,
on the local Kubernetes cluster, delivered declaratively, with one trace spanning
the whole path.

## In
- One simulated driver (`simulator/`), posting `position.reported` over HTTP with
  device sequence number and device timestamp.
- Ingest gateway: validates, normalizes, static token auth, writes to the log keyed by driver id.
- Event log: Apache Kafka 4.x in KRaft mode, one combined broker-and-controller node,
  one topic `position.reported` (`docker compose`: the official `apache/kafka` image;
  kind: the Strimzi operator with a `KafkaNodePool`).
- Location projector: consumes, keeps newest-by-sequence per driver in Redis
  (`HSET` + `GEOADD`), fleet-prefixed keys.
- Live gateway: WebSocket, pushes every update (no cells yet) to a static MapLibre page.
- Declarative deployment: kind cluster, Kustomize `local` overlay, Argo CD syncing `deploy/`.
- Delivery pipeline: GitHub Actions — build, `go test`, images to GHCR.
- One OpenTelemetry trace from simulator through the log to the WebSocket push.

## Out
Zones, orders, history, scaling, auth beyond a static token, cells, coalescing,
dedupe beyond newest-wins, metrics dashboards.

## Sittings (planned)
1. The pipe without Kubernetes: `docker compose` (Kafka, Redis, Tempo), one Go
   module, four binaries, dot moves, trace visible. Stop there.
2. Same on kind via Argo CD, Kafka through Strimzi; CI to GHCR; `make demo-r0`; ADRs; tag `v0.0`.

- [ ] ADR 0001 (source of truth), 0003 (delivery guarantee), 0005 (hot vs cold path) accepted.

## Deferred (found during the slice, not done here)
- Map page (`services/live-gateway/web/`) expects the live gateway to serve it at `/` and
  push `{driver_id, seq, lat, lon}` (one object or an array) on `/ws`; the gateway itself
  is still to build.
- The page carries a copy of `docs/design/console/tokens.css` (`go:embed` cannot reach
  `docs/`); one source once R2 creates `web/`.
- Dots step at report rate, no gliding; every driver draws as Available (R0 has no activity).
- Basemap reads public OpenFreeMap tiles and glyphs (Noto Sans labels, not the UI font);
  the demo needs network access until tiles are self-hosted.
